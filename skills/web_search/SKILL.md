# 网络搜索技能

## 能力

- **web_search(query, max_results)**：使用搜索引擎搜索关键词，返回按发布日期降序排列的标题、日期和摘要列表
- **fetch_url(url)**：抓取指定 URL 的页面内容并提取正文（去除 HTML 标签）

## 使用约定

- 搜索结果默认返回最多 5 条，可通过 max_results 参数调整
- fetch_url 对超过 4096 字符的页面自动截断
- 搜索前先思考：是否真的需要实时网络信息？已知信息优先使用，避免不必要的搜索
- 不要抓取需要登录才能访问的页面

## 搜索策略（时效性）

- 查询近期信息时，在关键词中加入当前年份（如 `Python 3.13 新特性 2025`）
- 结果已按发布日期降序排列，发布日期越新越靠前
- 若返回结果普遍发布于 2 年前以上，说明信息可能过时，应调整关键词重新搜索
- 综合多条结果时，优先采信发布日期更新的来源

## 准确性约束

- 报告给用户的 URL，只能原样使用 `web_search` 或 `fetch_url` 工具返回的内容，不得自行构造、推测或修改链接
- 若工具未返回相关结果，如实告知用户，不得用训练知识伪造结果格式

## 典型用法

```
任务：了解最新的 Python 3.13 新特性
步骤：web_search("Python 3.13 新特性 2025") → 选择权威来源 → fetch_url 获取详情
```
